Poisoned tools (MCP)

The attacker's text hides in a tool instead of the user's message: a tool description that orders a harmful action, a tool that turns malicious after you approve it (rug-pull), or a tool result that tells the agent to leak data through another tool. 5 scenarios against a worst-case obedient agent; an attack succeeds when a planted code leaves the sandbox by email.

Hidden injections

The words are still readable to the model, but a keyword detector no longer matches them: letters separated by invisible characters, look-alike letters from another alphabet, stretched spacing, or the instruction buried in HTML.
